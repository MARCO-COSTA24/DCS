==================================================
PROJETO: HELLO WORLD
==================================================

DESCRICAO
Este e um projeto simples em HTML criado para praticar 
os fundamentos de desenvolvimento web e controlo de 
versoes com Git e GitHub. A pagina exibe um titulo 
principal (h1) com a mensagem "Hello World".

TECNOLOGIAS UTILIZADAS
- HTML5
- CSS3
- Git e GitHub

ESTRUTURA DE FICHEIROS
- index.html : Pagina principal com o titulo h1.
- style.css  : Folha de estilos base.
- README.txt : Documentacao do projeto.

COMO EXECUTAR O PROJETO
1. Descarrega ou clona este repositorio para o teu computador.
2. Abre a pasta do projeto.
3. Faz duplo clique no ficheiro "index.html" para o abrir no navegador.
